# System Architecture

## Overview

The project is being developed as independent modules
that will be integrated into one application.

## Planned Modules

1. SAR Processing
2. Change Detection
3. Data Engineering
4. Geospatial Processing
5. Visualization

## Integration

Modules will communicate through documented inputs,
outputs and shared data formats.

The architecture will be updated as implementation progresses.

## Status

Initial architecture - subject to revision.
