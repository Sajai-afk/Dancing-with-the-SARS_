# Data Sources

## Primary Mission

NASA-ISRO Synthetic Aperture Radar (NISAR).

## Data Research

Record the following for every dataset:

- Product name and product type
- Acquisition date
- Polarization
- Frequency band
- Spatial coverage
- Processing level
- Source and download reference
- Relevant metadata

## Data Integrity

Do not treat sample or simulated data as real NISAR observations.

Document preprocessing and any limitations.
